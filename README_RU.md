**MeowClash** — это современный, многофункциональный мультиплатформенный прокси-клиент с открытым исходным кодом на базе ядра **ClashMeta (mihomo)**. Он предлагает красивый интерфейс в стиле Material You для управления вашими прокси-соединениями, полностью лишен рекламы и нативно работает на Android, Windows, macOS и Linux.

*MeowClash является форком отличного проекта [FlClashX](https://github.com/pluralplay/FlClashX).*

## 🎨 Ключевые возможности

### ✨ Интерфейс и стиль (Material You)
- **Интерфейс Material 3**: Чистый, современный, адаптивный дизайн, вдохновленный Surfboard.
- **Динамические темы**: Множество цветовых схем (TonalSpot, Fidelity, Monochrome, Neutral, Vibrant, Expressive, Content, Rainbow, FruitSalad) с поддержкой темного, светлого и глубокого черного режимов.
- **Настройка сетки и отступов**: Регулируйте плотность интерфейса (компактный, стандартный, просторный) и количество колонок (от 1 до 4) под размер экрана вашего устройства.
- **Адаптивный макет**: Автоматический переход между мобильным и десктопным интерфейсами.

### ⚙️ Прокси-движок (ClashMeta / mihomo)
- **Высокопроизводительное ядро**: Под капотом используется мощное ядро `mihomo` (написанное на Go).
- **Режимы маршрутизации**: Поддержка режимов «Правила» (Rule), «Глобальный» (Global) и «Прямой» (Direct).
- **Статистика в реальном времени**: Динамические графики скорости сети (загрузка/отдача) и учет общего трафика.
- **Управление группами прокси**: Сортировка узлов прокси по задержке, имени или конфигурации по умолчанию.
- **Автозакрытие соединений**: Автоматический разрыв активных подключений при смене прокси-узла.

### 🛡️ Сетевые и системные настройки
- **Системный прокси**: Быстрое включение и выключение системных настроек прокси для Windows и macOS.
- **Режим TUN**: Маршрутизация всего сетевого трафика системы через виртуальный сетевой адаптер (требуются права администратора/root).
- **Раздельное туннелирование (Access Control)**: (Android) Настройка черных и белых списков приложений, фильтрация системных приложений.
- **Переопределение DNS**: Настройка серверов имен (nameservers), DNS по умолчанию, fallback-серверов, прокси-серверов DNS, а также приоритет использования DOH (DNS-over-HTTPS) с поддержкой HTTP/3.
- **Доступ из локальной сети (AllowLan)**: Разрешение другим устройствам в локальной сети подключаться через ваш прокси.
- **Обход доменов (Bypass)**: Настройка списков доменов, которые должны направляться в обход системного прокси.
- **Поддержка IPv6**: Полное переключение маршрутизации входящего и исходящего IPv6-трафика.
- **Режим низкой памяти**: Включение режима низкого потребления памяти для баз данных Geo (Geo Low Memory Mode).

### ☁️ Синхронизация, шифрование и функции провайдеров
- **Синхронизация через WebDAV**: Резервное копирование и восстановление ваших профилей и настроек в облаке.
- **Дешифрование защищенных подписок**: Поддержка расшифровки зашифрованных подписок в формате base64 (AES-256-CBC, ключ выводится через PBKDF2) с использованием пользовательских заголовков `meowclash-password` и `meowclash-password-iterations`.
- **Обработка кастомных заголовков ответов**:
  - `announce`: Отображение объявлений и важных уведомлений внутри приложения.
  - `support-url`: Прямые ссылки на техподдержку в деталях профиля.
  - `profile-update-interval`: Задание интервала автообновления подписки.
  - `x-hwid-limit`: Проверка лимитов устройств с выводом специального диалогового окна регистрации HWID.

### 💻 Десктопная интеграция и утилиты
- **Сворачивание в системный трей**: Работа приложения в фоновом режиме после закрытия главного окна.
- **Параметры автозапуска**: Настройка запуска вместе с системой (Auto-launch) и скрытого запуска в фоне (Silent-launch).
- **Глобальные горячие клавиши**: Назначение клавиатурных сочетаний для показа/скрытия окна, запуска/остановки VPN, переключения режимов и управления TUN-режимом.
- **Разблокировка UWP-приложений (Loopback)**: (Windows) Утилита для быстрого включения сетевого доступа к локальному хосту для приложений из Windows Store (UWP).
- **Отправка на ТВ (TV Sync)**: Удобная передача профилей конфигурации на Android TV / Smart TV через сканирование QR-кода или локальную сеть.
- **Инструменты диагностики**: Просмотр текущих запросов в реальном времени, управление списком активных соединений, удобный вывод логов с экспортом в файл и сброс всех настроек приложения.

## 🔧 Системные требования для ОС

### Linux
Перед запуском приложения обязательно установите необходимые системные библиотеки:
```bash
sudo apt-get install libayatana-appindicator3-dev libkeybinder-3.0-dev
```

### Android
Поддерживается управление через сторонние инструменты автоматизации (например, Tasker) с помощью Intents (действий):
- **Запуск VPN**: `com.meowclash.app.action.START`
- **Остановка VPN**: `com.meowclash.app.action.STOP`
- **Переключение состояния**: `com.meowclash.app.action.TOGGLE`

## 🛠️ Сборка из исходников

### Требования
1. Установите **Flutter SDK (3.35.7)**.
2. Установите **Golang (1.24.0)** (требуется для сборки прокси-ядра).
3. При сборке для Windows: Установите **Rust** (актуальная версия, для вспомогательного сервиса Helper), **GCC** и **Inno Setup**.
4. При сборке для Android: Установите **Android SDK** и **NDK**, а также задайте переменную окружения `ANDROID_NDK`.

### Инструкция по сборке
1. **Клонируйте репозиторий вместе с подмодулями:**
   ```bash
   git clone https://github.com/Loischsiy/MeowClash.git
   cd MeowClash
   git submodule update --init --recursive
   ```

2. **Загрузите зависимости Flutter:**
   ```bash
   flutter pub get
   ```

3. **Сгенерируйте файлы моделей, провайдеров и локализации:**
   ```bash
   dart run build_runner build --delete-conflicting-outputs
   flutter pub run intl_utils:generate
   ```

4. **Соберите приложение с помощью скрипта сборки:**

   - **Android:**
     ```bash
     dart setup.dart android
     ```
   - **Windows:**
     ```bash
     dart setup.dart windows --arch <arm64 | amd64>
     ```
   - **Linux:**
     ```bash
     dart setup.dart linux --arch <arm64 | amd64>
     ```
   - **macOS:**
     ```bash
     dart setup.dart macos --arch <arm64 | amd64>
     ```

## 🔄 Особенности форка и важные изменения

### Рефакторинг системы переопределения провайдеров (Май 2026 г.)
Пользовательская система переопределения заголовков `meowclash-*` была полностью удалена. Ранее эти настройки считывались только из HTTP-заголовков ответа сервера подписки (а не из тела YAML самого профиля), из-за чего локальное переопределение в YAML-файлах профилей не имело силы.

- **Сохранено и полностью функционирует**:
  - **Дешифрование подписок**: Заголовки `meowclash-password` и `meowclash-password-iterations` для нативной расшифровки защищенного base64-содержимого подписки.
  - **Служебные заголовки ответов**: `announce` (информационный баннер), `support-url`, `profile-update-interval` (частота автообновления профиля) и `x-hwid-limit` (окно лимита привязанных устройств).
- **Удаленные параметры (теперь полностью настраиваются пользователем вручную)**:
  `meowclash-settings`, `meowclash-hex`, `meowclash-widgets`, `meowclash-view`, `meowclash-custom`, `meowclash-androidsecure`, `meowclash-servicename`, `meowclash-servicelogo`, `meowclash-serverinfo`, `meowclash-globalmode`, `meowclash-denywidgets`, `meowclash-background`. Теперь настройки автозапуска, фонового оформления и тем оформления всегда под полным контролем пользователя.
