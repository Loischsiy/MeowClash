## Project Context

**MeowClash** is a multi-platform proxy client (Android, Windows, macOS, Linux). It is a fork of [FlClashX](https://github.com/pluralplay/FlClashX), wrapping the [mihomo](https://github.com/MetaCubeX/mihomo) core (Go) with a Material You-based Flutter UI. The app supports subscription links, WebDAV sync, TUN mode, multiple color themes, and adaptive screen sizes.

**Package name:** `meowclash` (in pubspec)
**App display name:** MeowClash  
**Repository:** `Loischsiy/MeowClash`

## Core Version: Single Source of Truth

`core/constant/version.go` holds the canonical mihomo version string. **Do not hardcode versions elsewhere.**
- `setup.dart` reads it at build time and writes it to `lib/core_version.dart`.
- It is injected into Go linker flags during compilation.
- Update this file when bumping mihomo in `core/go.mod`.

## Build System (`setup.dart`)

The main build script is `setup.dart`, which handles Go cross-compilation and packaging.

### Local Commands
| Task | Command |
|------|---------|
| Android (arm64) | `make android_arm64` or `dart setup.dart android --arch arm64` |
| macOS (arm64) local | `make macLocal` |
| Core only | `dart setup.dart <platform> --arch <arch> --out core` |
| Nix Linux package | `nix build .#meowclash` |

### Platform Behaviors
- **Android:** Builds `libclash.so` (CGO) for all ABIs. Produces split and universal APKs.
- **Desktop:** Builds `MeowClashCore` executable (Go, no CGO).
- **Windows:** Builds Rust `helper.exe` and packages into EXE + ZIP.
- **Nix/NixOS:** Uses `buildGoModule` and `buildFlutterApplication` (does not use `setup.dart`). Currently `x86_64-linux` only.

## NixOS TUN Mode

Use the flake module for TUN mode on NixOS:
```nix
{
  imports = [ inputs.meowclash.nixosModules.default ];
  programs.meowclash.enable = true;
  programs.meowclash.tunMode.enable = true;
}
```
The module creates a `/run/wrappers/bin/MeowClashCore` wrapper with `cap_net_admin+ep`. The app searches this path to allow TUN mode without mutating the read-only Nix store.

## Coding Standards

### Naming Conventions
- **Files:** `snake_case.dart` — one main class or concern per file
- **Classes/Enums:** `PascalCase`
- **Variables/Functions:** `camelCase`
- **Private members:** `_underscorePrefix`
- **Barrel files:** `common.dart`, `models.dart`, `widgets.dart` — re-export public symbols

### State Management (Riverpod)
- Use `@riverpod` annotation + `build_runner` for auto-generated providers
- Notifier classes use `AutoDisposeNotifierMixin` by default
- Shared mutable state via `GlobalState` singleton with `ValueNotifier`

### Models (Freezed)
- All data models annotated with `@freezed` (immutable, `copyWith`)
- `part 'generated/name.freezed.dart';` and `part 'generated/name.g.dart';`

### Linting (Strict)
- `always_declare_return_types`, `avoid_print`, `prefer_const_*`, `prefer_final_locals`
- `unawaited_futures` — fire-and-forget must use `unawaited()`
- `use_key_in_widget_constructors`
- Generated code excluded from analysis.

### Error Handling
- `globalState.safeRun()` wrapper for async operations
- `commonPrint` for structured logging, `fileLogger` for persistent logs

## Common Gotchas

- **Missing `plugins/flutter_distributor/`?** Expected locally; cloned by CI or `setup.dart`.
- **Missing `libclash/`?** Build output directory for core binaries; created by `setup.dart`.
- **ffigen header path** is hardcoded to `libclash/android/arm64-v8a/libclash.h`. Android core must be built first to regenerate FFI bindings.
- **NixOS TUN:** App must show the NixOS module hint if `tunMode.enable` is false instead of attempting to `chown`.

## Change Log — `meowclash-*` provider-override system removed (2026-05)

The custom `meowclash-*` override system was fully removed (variant B = full physical deletion). These keys were read **only** from the subscription's HTTP **response headers**, never from the profile YAML body. **Subscription decryption was deliberately kept fully working.**

### Removed (deleted / no-op now)
Headers no longer handled: `meowclash-settings`, `meowclash-hex`, `meowclash-widgets`, `meowclash-view`, `meowclash-custom`, `meowclash-androidsecure`, `meowclash-servicename`, `meowclash-servicelogo`, `meowclash-serverinfo`, `meowclash-globalmode`, `meowclash-denywidgets`, `meowclash-background`.

### Kept — MUST stay functional
- **Subscription decryption:** `meowclash-password`, `meowclash-password-iterations`, `_maybeDecrypt`, `SubscriptionCrypto`, `Profile.update(decryptionPassword, decryptionIterations)`.
- Non-override headers: `announce`, `support-url`, `profile-update-interval`, `x-hwid-limit`.

### Follow-ups
- Run `dart run build_runner build --delete-conflicting-outputs` then `flutter analyze`.
- `overrideProviderSettings` model field is still present to avoid migration.
- Dead widgets: `service_info_widget.dart`, `change_server_button.dart` still exported.
